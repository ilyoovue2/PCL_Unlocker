# PCL_Unlocker

**注意：** 本项目由DeepSeek-V4.1-Flash-1017完成，代码部分无人工参与

针对 **Plain Craft Launcher 2.99.0.1 正式版** 的离线补丁工具，用于恢复 2.99 更新中因合规原因被移除的 Minecraft 下载入口。

> 说明：PCL 2.99 起在 `ModSecret.RestrictMcDownload` 中关闭了 MC 下载功能。本工具只修改你本地的 exe，用于个人学习与本地恢复；请自行确认使用场景符合当地法律法规，不要分发修补后的二进制文件。

## 支持版本

| 项目 | 值 |
| --- | --- |
| 程序集 | `Plain Craft Launcher 2` |
| 版本 | `2.99.0.1` |
| 文件大小 | `6,013,952` 字节 |
| SHA256 | `0DB34E19D9EEB6D496D20FABE786EC16BBD36BA6B0CCDC8D29CB7E909C114397` |

工具会校验程序集名称、版本和 SHA256；版本不符会直接拒绝，避免把错误版本的 IL 改坏。

## 恢复的内容

| 编号 | 恢复项 |
| --- | --- |
| P01 | 下载页左侧“原版游戏”和“社区资源” |
| P02 | 原版游戏版本列表使用真实的 `DlClientListLoader` |
| P03 | 启动页无版本时显示“下载游戏” |
| P04 | 实例禁用 Mod 页的下载按钮 |
| P05 | 版本选择页空状态下的下载按钮 |
| P06 | 版本选择页“导入整合包” |
| P07 | 资源页“安装整合包”搜索按钮 |
| P08 | 版本修改页的 Minecraft 卡片 |
| P09 | MC 更新提示里的“下载”按钮 |
| P10 | 无参 `ModpackInstall()` 的文件选择与后台安装入口 |
| P11 | 整合包安装的 7 路类型分发（CurseForge / HMCL / MMC / MCBBS / Modrinth / 启动器包 / 普通压缩包） |
| P12 | 整合包资源版本列表的“安装”点击入口 |

> 2.99 的 VB 编译器把 `RestrictMcDownload = True` 内联并删除了部分死代码，所以不能只改常量或做字节替换；本工具用 [dnlib](https://github.com/0xd4d/dnlib) 重写 IL，并补回被删除的分支。

## 构建

通过Visual Studio 2026，工作负荷勾选.NET桌面开发构建

## 使用

下载发行版中的压缩包并解压，将其中的6个文件复制到PCL启动器目录并运行`PCLUnlocker.exe`（会自动找到 `\Plain Craft Launcher 2.exe`）：

发布版是框架依赖的 .NET 10 程序；目标机器需要安装 .NET 10 运行时（源码构建同样需要 SDK）。

### 原地修补时的备份

首次原地修补会在 exe 旁边生成：

```
\Plain Craft Launcher 2.exe.pclunlocker.bak
```

这是原始文件的备份。将文件名修改回Plain Craft Launcher 2.exe即可恢复。

如果 PCL 正在运行，工具会拒绝写入；请先关闭启动器。

## 限制与注意事项

- **版本绑定**：只支持 2.99.0.1；PCL 更新后方法 IL 可能变化，工具会拒绝而不是误补。
- **自动更新**：PCL 更新会覆盖补丁；更新后需要重新运行本工具。
- **网络依赖**：补丁只解除客户端入口限制，实际下载仍依赖 Mojang / BMCLAPI / Modrinth 等服务可达。
- **隐藏设置**：如果你曾在“设置 → 隐藏功能”中勾选“下载”，主导航可能仍按该设置隐藏；本工具已恢复启动页、空版本页等入口，也可以在设置中关闭该隐藏项。
- **杀软误报**：dnlib 重写过的 exe 可能被部分杀软标记，建议本地构建并添加信任。
- **备份**：建议保留修补后生成的 `Plain Craft Launcher 2.exe.pclunlocker.bak`以备用。
- **合规**：请仅在符合当地法律法规的前提下使用；本项目不鼓励或协助任何违法用途。
